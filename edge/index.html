      Checking your voices… How to get a more human voice
      Easiest: Microsoft Edge

      Open this page in Microsoft Edge (free on Mac and Windows). It has built-in "Natural" voices like Ava, Andrew, Emma and Brian. Pick one marked ★ natural above.

      On a Mac

      System Settings → Accessibility → Spoken Content → System voice → Manage Voices. Under English, download a voice marked Premium (for example Ava or Zoe). Then reload this page in Safari or Chrome.

      On Windows

      Settings → Time & language → Speech → Manage voices → Add voices, then reload. Or simply use Edge.
