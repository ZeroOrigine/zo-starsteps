# Star Steps

Little steps. Big climbs. A learning game for ages 5 to 12, built by Advik.

16 subjects, 810 skills, 7 grades (Kindergarten to Grade 6). Zero network calls, zero data collection, works fully offline. Ships as a PWA at https://starsteps.zeroorigine.com

Part of the ZeroOrigine ecosystem as an isolated venture: no shared database, no shared marketing automation.
